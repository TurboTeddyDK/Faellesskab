1.  **Gennemsigtighed ved bonusser:** Alle listede tilbud (f.eks. indbetalingsbonusser og gratis chancer) præsenteres med de væsentligste vilkår og eventuelle omsætningskrav (f.eks. 10x) direkte synligt i tabellen.
